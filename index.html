Seção 1

O que são Variáveis?

Entenda o mecanismo fundamental que permite aos computadores armazenar, manipular e consultar dados em tempo de execução.

A Analogia da Caixa Etiquetada

Imagine que a memória RAM do computador é um grande depósito com gavetas e caixas. Uma variável funciona exatamente como uma caixa com uma etiqueta de identificação:

A etiqueta é o nome da variável (ex.: nome), enquanto o que é colocado dentro da caixa é o valor guardado para uso posterior (ex.: "Maria").

nome
"Maria"
Tipo: str (String de Texto)
RAM: 0x7ffeef89c310
idade
18
Tipo: int (Inteiro)
RAM: 0x7ffeef89c330

Em Python: A variável não guarda o dado diretamente; ela atua como uma referência (ponteiro) que aponta para o objeto residente na memória. Quando você altera o valor, o Python redireciona a etiqueta para um novo endereço de forma transparente!

Boas Práticas & Sintaxe

Regras de Nomenclatura de Variáveis

Convenções da linguagem Python (PEP 8) e regras universais para escrever identificadores limpos, legíveis e livres de erros de compilação.

CORRETO (Boas Práticas)
  • nome = "Ana"
    Nomes claros, objetivos e autoexplicativos. Facilita a manutenção do código.
  • idade_aluno = 16
    Uso de snake_case (palavras separadas por underline _), o padrão oficial do Python (PEP 8).
  • precoTotal = 25.50
    camelCase é sintaticamente válido em Python e padrão nativo em JavaScript/Java.
  • usuario_ativo = True
    Prefixos como is_, has_ ou adjetivos são ideais para indicar variáveis booleanas.
  • PI_CONSTANTE = 3.14
    Nomes em SCREAMING_SNAKE_CASE indicam constantes que não devem ser alteradas.
EVITE OU ERRO DE SINTAXE
  • 1nome = "Ana"
    SyntaxError: Variáveis NÃO podem começar com números. O compilador confunde com literais numéricos.
  • nome completo = "Ana"
    SyntaxError: Variáveis NÃO podem conter espaços em branco. O interpretador lê como duas instruções soltas.
  • idade-aluno = 16
    SyntaxError: O hífen é lido pelo interpretador como o operador aritmético de subtração (idade - aluno).
  • x = "Ana"
    Má Prática: Nomes com apenas uma letra são vagos e prejudicam a compreensão do sistema.
  • class = "A"
    SyntaxError: Não se pode usar palavras reservadas da linguagem (ex.: class, def, for, import).

Seção 2

Tipos de Dados Primitivos e Compostos

Cada tipo de dado determina a quantidade de memória alocada, a precisão e as operações aritméticas ou lógicas possíveis.

int

Primitivo

Representa números inteiros (positivos, negativos ou zero) sem qualquer fração ou casa decimal. No Python 3, a precisão é ilimitada (limitada apenas pela memória RAM).

quantidade = 10
temperatura = -42
contador = 0
Memória: 28 bytes (objeto Python)

float

Primitivo

Números reais ou com ponto flutuante (casas decimais). Baseia-se no padrão IEEE 754 de precisão dupla de 64 bits (aproximadamente 15 a 17 dígitos de precisão).

pi = 3.14159
preco = 19.90
saldo = -150.75
64-bit Double Precision

bool

Primitivo

Tipo booleano fundamentado na álgebra de George Boole. Possui apenas dois estados lógicos fundamentais: True (Verdadeiro) ou False (Falso).

estudante = True
bloqueado = False
maior_idade = 18 >= 18 # True
Subtipo de int no Python

char

Primitivo (C/Java)

Armazena um caractere alfanumérico individual ('A', '7', '$'). Em C/Java é um primitivo de 8/16 bits; em Python, é tratado de forma transparente como uma string de tamanho 1.

# Em Python: str de comprimento 1
letra = 'A'
simbolo = '$'
codigo_ascii = ord('A') # 65
Tabela ASCII & Unicode

string (str)

Texto / Primitivo

Cadeia ordenada e imutável de caracteres Unicode. Permite interpolação com f-strings (f"..."), fatiamento (slice), concatenação e busca indexada.

mensagem = "Olá, mundo!"
cidade = "Palmas"
apresentacao = f"{mensagem} Bem-vindo a {cidade}."
Objeto Imutável na RAM

byte / bytes

Dados Brutos

Sequência de dados binários de 8 bits (valores de 0 a 255). Essencial em protocolos de rede TCP/IP, criptografia, leitura de arquivos binários e streams de dados.

dados_binarios = b"Python"
byte_array = bytearray([65, 66, 67])
print(byte_array) # bytearray(b'ABC')
Redes, Arquivos & Cripto

Vetores & Matrizes

Composto (list)

Estruturas dinâmicas, ordenadas e mutáveis. Vetores 1D ([10, 20, 30]) e Matrizes bidimensionais (linhas e colunas em listas aninhadas).

# Vetor 1D:
vetor = [10, 20, 30]
# Matriz 2x2:
matriz = [[1, 2], [3, 4]]
Acesso por índice O(1)

Dicionários & Objetos

Composto (dict)

Mapeamento de pares chave-valor (semelhante ao JSON). As chaves são hasheadas para garantir busca, inserção e remoção em tempo ultrarrápido $O(1)$.

aluno = {
  "nome": "Maria",
  "idade": 18,
  "matriculado": True
}
Hash Table O(1)

Enumerações (enum)

Composto (Enum)

Conjunto de constantes simbólicas nomeadas. Evita "números mágicos" ou strings soltas no código, prevenindo erros de digitação e aumentando a legibilidade.

from enum import Enum

class Status(Enum):
  ATIVO = 1
  PENDENTE = 2
  CANCELADO = 3
Type Safety & Legibilidade

Data Science

Como Declarar em Cada Linguagem

Selecione um tipo para inspecionar e copiar o código em Python, JavaScript, Java e C:

Python 
# Inteiro em Python (tipagem dinâmica)
x = 10
print(type(x))  # <class 'int'>
Tipagem dinâmica e forte. Sem ponto e vírgula.
JavaScript 
// Inteiro em JavaScript
let x = 10;
console.log(typeof x); // "number"
Tipo genérico number para inteiros e decimais.
Java 
// Inteiro em Java (estaticamente tipado)
int x = 10;
System.out.println(x);
Tipagem estática: tipo declarado antes do nome.
C (ANSI C) 
/* Inteiro em C (32 bits com sinal) */
int x = 10;
printf("%d\n", x);
Controle direto de memória e tipos com sinal.
No Python 3, inteiros têm precisão arbitrária ilimitada (bignum). Em C e Java, int tem limite de 32 bits (máx 2.147.483.647).

As 3 Dicas de Ouro na Programação

Pegadinhas clássicas que todo desenvolvedor profissional deve dominar para evitar falhas silenciosas e prejuízos em produção.

Dica 1 • Sintaxe

Aspas Simples ('A') vs. Duplas ("A")

Em linguagens compiladas como C, C++ e Java, a diferença é estrita: 'A' representa o tipo primitivo char (1 byte, código ASCII 65), enquanto "A" representa um ponteiro/objeto da classe String!

Já em Python e JavaScript, ambas têm exatamente o mesmo comportamento para strings. A boa prática é manter a consistência no projeto (PEP 8).

// Java/C: Erro se misturar!
char c = 'A'; // Correto
char c2 = "A"; // Erro de compilação!
# Em Python: tanto faz
s1 = 'A' == "A" # True
Dica 2 • Financeiro

NUNCA use Float para Valores Monetários!

Os processadores utilizam a base binária (potências de 2) para armazenar números flutuantes (IEEE 754). Frações decimais simples como 0.1 e 0.2 tornam-se dízimas periódicas infinitas em binário, gerando imprecisões catastróficas em contas bancárias.

Solução: Guarde os valores em centavos inteiros (R$ 19,90 = 1990) ou use o módulo decimal.Decimal em Python.

# O bug clássico do float:
0.1 + 0.2 == 0.3 # False!
0.1 + 0.2 # 0.30000000000000004
# Correto com Decimal:
Decimal('0.1') + Decimal('0.2') == Decimal('0.3') # True
Dica 3 • Arquitetura

Atenção ao Estouro de Memória (Overflow)

Em linguagens com tipagem estática (C, C++, Java), um inteiro de 32 bits com sinal tem limite máximo de 2.147.483.647 ($2^{31} - 1$). Ao somar 1 a esse valor, ocorre o overflow e o número passa a ser negativo!

O diferencial do Python 3: Os inteiros possuem precisão arbitrária. Se o número crescer, o Python aloca mais memória dinamicamente, evitando o temido overflow.

/* Em C: estouro perigoso */
int max = 2147483647;
max + 1; // Resultado: -2147483648 (Bug!)
# Em Python 3: cresce na RAM
2**100 # 1267650600228229401496703205376
